系統定位

acore 系統簡介

acore 是一個離線的 Chrome 2FA 擴充功能。

安全原則

01

不儲存明文

資料寫入 chrome.storage.local 前皆已加密，無主密碼無法解密。

02

無外部連線

外掛無外部網路請求，所有計算在本地完成。

03

記憶體防護

計算完成後立即清除記憶體中的明文，防止傾印。

架構設計

前端 UI 與 Background Worker 使用動態加密 IPC，防止訊息攔截：

網頁前端 UI 隔離層 (Popup - 不持有密鑰)
1-to-1 動態 ECDH 金鑰加密 IPC
密碼學核心沙盒 (Background SW - 僅在記憶體解密)
AES-GCM (256-bit)
本地加密儲存區 (chrome.storage.local - 密文狀態)
部署說明

安裝指南

acore 完全本地執行，請載入專案資料夾即可。

逐步安裝指引

第一步：下載專案原始碼

將 acore 外掛專案包解壓縮到您本地電腦的指定目錄（例如 C:\acore）。

第二步：開啟開發人員模式

在 Chrome 瀏覽器網址列輸入 chrome://extensions/，進入擴充功能管理頁面，並勾選右上角的「開發人員模式」。

第三步：載入未封裝項目

點擊「載入未封裝項目」，選擇專案資料夾即可。

安全性深度分析

密碼學架構

系統基於 Web Crypto API 實作。

金鑰衍生與加密

A

PBKDF2

主密碼 + 16-byte Salt 經 100,000 次 SHA-256 迭代衍生 256-bit KEK。

B

AES-GCM

資料寫入前使用 AES-GCM (256-bit) 加密，附帶 12-byte IV 與驗證標籤。

ECDH IPC

Popup 與 Background 之間使用 ECDH (P-256) 交換金鑰，建立 AES-GCM 加密通道通訊，防止攔截。

檔案規格

備份檔案格式

導出的 JSON 備份檔使用相同加密機制，可用於離線保管。

JSON 備份資料格式規格

當使用者選擇導出備份時，背景程式會將整個加密儲存庫包裝成 JSON 導出。以下為其完整的資料規格格式：

acore_backup_schema.json 
{
  "salt": "uWz6H0bN2rD58iPqQvL9+A==",  // 用於衍生 KEK 的 16 字節 CSPRNG 隨機鹽值 (Base64)
  "sentinel": {
    "iv": "kPn9XmYt5Rq1aBc7",         // Sentinel 加密使用之 12 字節 IV (Base64)
    "ciphertext": "z8JqP+4dFh2..."    // 解密後應為 "ZeroTrustSentinel" (AES-GCM 密文)
  },
  "vault": {
    "iv": "wQe9RnT5Yu3iOp8A",         // 密鑰資料庫加密之 12 字節 IV (Base64)
    "ciphertext": "a1b2C3d4E5f6..."   // 解密後為包含帳戶金鑰的 JSON 陣列密文
  },
  "logs": {
    "iv": "zXy8Wv2Ts5Rq9PmN",         // 安全審計日誌加密之 12 字節 IV (Base64)
    "ciphertext": "m9n8B7v6C5x..."    // 解密後為歷史審計日誌之 JSON 陣列密文
  }
}

還原流程

使用備份時的密碼解密，並以當前系統金鑰重新加密寫入。

合規審計

審計日誌規範

系統會在本地紀錄操作日誌 (如：解鎖、新增、自動填入)，並加密儲存。

日誌物件架構規格

每次使用者進行關鍵操作（如解鎖、新增金鑰、複製驗證碼、自動填入或匯出備份）時，系統皆會將該操作時間戳與詳細內容加密寫入日誌庫中。

audit_log_schema.json 
[
  {
    "timestamp": 1780560000000,              // 事件發生的毫秒級時間戳
    "event": "Vault initialized"            // 事件行為描述
  },
  {
    "timestamp": 1780560120000,
    "event": "Added account: Discord (admin)"
  },
  {
    "timestamp": 1780560250000,
    "event": "Copied TOTP for: Discord:admin"
  },
  {
    "timestamp": 1780560300000,
    "event": "Autofilled TOTP for: Discord (admin)"
  }
]
